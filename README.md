# IT Website (static version)

This folder contains a static HTML, CSS and JavaScript version of the existing five-page site. The original WordPress project is preserved separately.

## Pages

- `index.html` — home page
- `about.html` — about page
- `services.html` — services page
- `gallery.html` — case studies page
- `contact.html` — contact page

Styles, scripts and images are in `assets/`.

## Publish with GitHub Pages

1. Create or open a GitHub repository for this static site.
2. Upload the **contents of this folder** to the repository root (so `index.html` is at the root).
3. In the repository, open **Settings → Pages** and select deployment from the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

GitHub Pages serves this static version. It does not run WordPress, PHP, plugins, themes dynamically, or the WordPress admin/database. Continue editing the original WordPress copy separately.

The WhatsApp bubble opens WhatsApp Web in a new tab. Its green signal pulse stays within 1.5 CSS pixels of the bubble edge (about 0.4 mm).

The contact form prepares a message in the visitor's email app; it does not submit to a web server. The email address and phone number are the contact details already present in the source and should be confirmed before publication. Some existing links and social destinations are still placeholders.
